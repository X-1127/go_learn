一、go的项目结构：
    1.基础的三部分：main package go.mod
        main：主函数所在目录
        package：公共文件所在目录，可在main.go中导入
        go.mod：
            A.告诉编译器根目录叫什么
            B.引入第三方库时自动记录库名和版本号
            C.记录go的版本号

二、go的Hello代码
    1.代码示例：
        package main
        import "fmt"
        func main(){
            fmt.Println("Hello World")
        }
    2.代码分析：
        package main：声明该文件所在包，go文件必须归属一个包
        import “fmt”：导入fmt包，因为需要使用其函数：Println来执行输出
        func main（）：主函数，程序入口，与C++类似
        {}：函数体部分，必须用大括号
        fmt.Println：fmt的一种输出方式

三、go代码执行
    1.执行操作：
        go run ./main/main.go：直接运行（也是先编译再运行）
        go build ./main/main.go：先编译生成main.exe以供运行
    2.区别：
        A.编译时，编译器会将程序运行依赖的库文件包含在可执行文件中
        B.先编译成可执行文件可以方便将该文件移动到其他没有go环境的计算机上执行
        C.在另一个计算机上直接go run运行需要go开发环境
