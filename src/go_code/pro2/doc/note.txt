一、数据类型转换注意事项
    1.基本数据类型转换方法:T(n)
    2.注意溢出
    3.运算符两边必须统一数据类型

二、基本类型转字符串
    1.Sprintf方法：
        var n1 int = 19
        var s1 string = fmt.Sprintf("%d",n1)
    2.strconv方法：(不常用)
        var n1 int = 19
        var s1 string = strconv.FormatInt(int64(n1),10)

三、字符串转换基本类型
    1.Parse方法：
        var s1 string = "true"
        var b bool
        b, _= strconv.ParseBool(s1)

        var s1 string = "64"
        var b int64
        b, _ = strconv.ParseInt(s1, 10, 64)
